# NovaTech — Sample 3-page website

A small static website for learning Git and GitHub.

## Pages
- `index.html` — Home
- `about.html` — About
- `contact.html` — Contact (demo form only)
- `style.css` — Shared styles

## Run locally
Open `index.html` in your browser. No build tools are required.

## Git practice
Follow the Git commands in the accompanying tutorial or use this project to practice:
1. Initialize a repository and commit the starting website.
2. Create an empty GitHub repository and push `main`.
3. Create a feature branch, edit a page, commit, and push the branch.
4. Pull changes from GitHub into your local branch.
5. Optionally make the same line change on two branches to practice a merge conflict.
